# Sistema de inventario - Farmacia Cruz Verde

## Abrir en Windows

1. Descarga el proyecto desde GitHub: abre el repositorio y selecciona **Code > Download ZIP**.
2. En Windows, haz clic derecho en el ZIP y selecciona **Extraer todo**.
3. Abre la carpeta extraída y haz doble clic en **Abrir inventario.bat**. Se abrirá el sistema en tu navegador predeterminado.

También puedes abrir directamente `index.html` con doble clic. Mantén `index.html`, `script.js` y `styles.css` juntos en la misma carpeta.

## Datos

Los productos se guardan en el almacenamiento local del navegador y quedan disponibles en ese navegador y equipo. Si se borran los datos del navegador o se usa otro navegador, no aparecerán allí.
